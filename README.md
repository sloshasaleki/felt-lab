# Felt Lab — Hold'em Trainer

An offline No-Limit Hold'em training app: lessons (including a companion course to Andrew Seidman's *Easy Game*, summarised in original words), drills with spaced repetition, a coached table against bots, and equity / range / push-fold / ICM / variance tools.

Open the GitHub Pages address in Chrome and choose **Install app**. Everything runs on the device; progress is stored locally.
